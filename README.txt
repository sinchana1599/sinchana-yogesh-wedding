SINCHANA & YOGESH - WEDDING WEBSITE

Preview locally:
1. Extract the ZIP file.
2. Open the sinchana-yogesh-wedding-site folder.
3. Open index.html in a browser. Keep the assets folder beside it.

Publish on Vercel:
1. Extract the ZIP file.
2. Create a GitHub repository and upload the contents of the sinchana-yogesh-wedding-site folder (index.html, wedding.ics, and assets folder).
3. Sign in to Vercel and choose Add New -> Project.
4. Import the GitHub repository.
5. Keep the framework preset as Other; leave build and output settings empty/default for this static site.
6. Select Deploy. Vercel will provide a public URL to share.

The site uses Google Fonts from the internet. All six uploaded photos are included locally in assets.
